Product Crawler

A tool I built to help Inventory Control identify products with low or no stock across the UNIQLO Canada website.

Python PowerShell Google Sheets Tableau
The Problem

Inventory Control needed a way to identify products with low or no stock across the website so they could keep track of pages that needed attention.

However, there was no record of which products appeared on which pages. The existing process involved manually checking products and guessing which pages they appeared on, making it too time-consuming to do regularly.

The Challenge

The information needed for the process already existed, but it lived in different places.

Stock information was available in Tableau and the website sitemap was available through the CMS, but neither connected product IDs to the pages where they appeared.

I needed to build that missing connection.

My Approach

I built a Python and PowerShell crawler that connects the existing stock data with the products found across the website.

  1. Import stock data from Tableau into Google Sheets.
  2. Place the current website sitemap into the tool.
  3. Crawl 250+ product pages to identify product IDs on each URL.
  4. Map product IDs to their stockout information.
  5. Generate actionable results in Google Sheets.
Designed for the Team

I designed the workflow around the team's existing Google Sheets process rather than introducing a new interface.

The tool uses one button to start the crawl, includes instructions in the sheet, hides helper sheets, and provides a Settings tab where the stockout threshold can be adjusted.

The current crawl takes approximately 10–15 minutes to complete.

Outputs

The tool produces two main outputs: an actionable list of pages requiring attention and a summary of website stockout performance.

Where It's Going

The current version is still being refined and prepared for presentation to GHQ.

Future iterations could incorporate sales goals and GA4 data to provide additional context around stockout and website performance.
